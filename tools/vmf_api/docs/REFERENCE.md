## HTTP commands

|---|---|---|---|
| `apply_config` | `path`, `faces?`, `no_control?`, `no_params?`, `source_face?`, `missing?`, `dry_run?` | `apply_config` | Import someone else's preset/workspace without overwriting personal settings. Automatic backup first (restore_backup to undo). |
| `apply_offline` | `path`, `workspace?`, `faces?`, `no_control?`, `no_params?`, `source_face?`, `missing?`, `dry_run?`, `force?` | client | VisoMaster CLOSED: same merge directly into last_workspace.json (backup vmf_api/backups/last_workspace.json.bak-<date>). force=true only if VisoMaster is really closed but its process could not be checked. |
| `batch_input_faces` | `input_faces?`, `face_id?` | `batch_input_faces` | Swap the current frame (image, or video frame at the playhead) once per loaded input face (all, or the listed file names / ids), each one alone on the target face (default: selected face), and save each result to OutputMediaFolder as <media>__<input face>.png (.jpg with ImageFormatToggle), like Save Image; an existing file is never overwritten (_2, _3... added).
